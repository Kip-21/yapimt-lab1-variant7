# ЯПиМТ — лабораторная работа № 1, вариант 7

Основные элементы языка ассемблера. MASM, Win32.

Программа вводит восьмеричное число **x**, показывает его десятичную запись,
вычисляет **11x² − 2x + 1** и выводит результат в двоичной и десятичной системах.
