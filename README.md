# ЯПиМТ — лабораторная работа № 1, вариант 7

Основные элементы языка ассемблера. MASM, Win32.

Программа вводит восьмеричное число **x**, показывает его десятичную запись,
вычисляет **11x² − 2x + 1** и выводит результат в двоичной и десятичной системах.

Код и отчёт находятся в отдельных папках. Чтобы пересобрать PDF, откройте папку
`report` и выполните:

```bat
xelatex -interaction=nonstopmode -halt-on-error report.tex
```

XeLaTeX автоматически включает `report/титульник.pdf` первой страницей.
Скриншоты тестов берутся из папки `тесты`, листинг — из `code/main.asm`.
Для сборки сохраните структуру папок и установите пакет LaTeX `pdfpages`.
