# Лабораторная работа № 1, вариант 7

Программа на MASM для 32-разрядной Windows. Вводит восьмеричное целое x,
показывает x в десятичной системе, вычисляет 11*x*x - 2*x + 1 и выводит
результат в двоичной и десятичной системах. Работает и в 64-разрядной Windows.

## Быстрый запуск

В папке уже есть собранный `lab1.exe`. Дважды щёлкните `run.bat`:
он запускает программу и оставляет окно открытым после завершения.
Введите число и нажмите Enter. Например, для `10` (это 8 в десятичной системе):

```text
Enter x in base 8 (digits 0-7, optional minus): 10
x (decimal) = 8
11*x*x - 2*x + 1 (binary) = 1010110001
11*x*x - 2*x + 1 (decimal) = 689
```

Допускаются цифры 0–7, начальный минус и ведущие нули: `0`, `123`, `-10`, `00017`.
Пробелы, плюс, префиксы и индексы системы счисления вводить не нужно.
Рабочий диапазон: от -13972 до 13972 в десятичной системе
(от `-33224` до `33224` в восьмеричной). Все промежуточные значения помещаются
в знаковое 32-разрядное число. Ошибочный ввод или переполнение завершают
программу с сообщением `Error` и кодом 1; успешный запуск возвращает 0.
Приглашения на английском используют ASCII и не зависят от кодовой страницы.

## Сборка из исходного кода

Нужны Visual Studio либо Build Tools с компонентами «Разработка классических
приложений на C++», средствами MSVC для x86/x64 и Windows SDK.

1. Откройте **x86 Native Tools Command Prompt for Visual Studio** в меню «Пуск».
2. Перейдите в папку кода:

   ```bat
   cd /d "C:\Users\Kip\Documents\Учеба\7 семестр\ЯПИМТ\1 lab\code"
   ```

3. Выполните `build.bat`, затем `run.bat`.

`build.bat` вызывает 32-разрядный MASM (`ml`, не `ml64`) и компоновщик:

```bat
ml /nologo /c /coff /Zi main.asm
link /nologo /subsystem:console /machine:x86 /debug /out:lab1.exe main.obj kernel32.lib
```

В PowerShell готовую программу можно запускать командой `./lab1.exe`.
Вводить данные нужно с клавиатуры в консоли: перенаправление из файла и конвейер
не поддерживаются функцией ReadConsoleA, выбранной по методичке.

## Отладка в Visual Studio

Создайте пустой проект C++ и выберите платформу Win32/x86. В меню проекта
«Зависимости сборки → Настройки сборки» включите MASM, добавьте `main.asm`.
Для файла должен быть выбран тип элемента Microsoft Macro Assembler.
В свойствах компоновщика задайте «Система → Подсистема → Консоль»,
«Ввод → Дополнительные зависимости → kernel32.lib».
Директива `END MAIN` задаёт точку входа; другой исходный файл с main не нужен.
Включите отладочную информацию ассемблера и компоновщика.

Поставьте точку останова на `MOV EAX, x` перед вычислением квадрата.
Пошагово выполняйте команды и наблюдайте переменные `x`, `square`, `quadratic`,
`linear`, `partial`, `result` в окнах «Контрольные значения» и «Память».
При вводе `10` они последовательно получают значения 8, 64, 704, -16, 688, 689.
Окна «Регистры» и «Дизассемблированный код» доступны во время остановки отладки.
После PUSH значение ESP уменьшается на 4, а в вершину стека записывается аргумент;
CALL дополнительно помещает адрес возврата. Функции STDCALL сами убирают аргументы.

## Файлы

- `main.asm` — вся программа; дополнительных библиотек кроме kernel32.lib нет.
- `build.bat`, `run.bat` — сборка и запуск.
- `tests.txt` — проверенные входные данные и результаты.
- `../report/report.tex` и `../report/report.pdf` — исходник и готовый отчёт.

Чтобы пересобрать отчёт, откройте папку `report` и выполните
`xelatex -interaction=nonstopmode -halt-on-error report.tex` дважды.
Нужен MiKTeX или TeX Live с XeLaTeX. Листинг берётся прямо из `../code/main.asm`:
сохраняйте расположение обеих папок.
