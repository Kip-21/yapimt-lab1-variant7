# Краткие ответы для защиты лабораторной № 1

1. **GetStdHandle(n)** возвращает дескриптор стандартного потока: -10 — ввод,
   -11 — вывод, -12 — ошибки. Пример: `PUSH -10; CALL GetStdHandle@4`, результат в EAX.
2. **WriteConsoleA(h, buffer, length, &written, 0)** выводит length символов
   в консоль; written получает фактическое количество. Нуль в конце не обязателен.
   В программе эта функция вызывается из PrintText.
3. **CharToOemA(source, destination)** переводит строку из Windows ANSI
   в OEM-кодировку; адреса могут совпадать. Пример: дважды `PUSH OFFSET text`,
   затем `CALL CharToOemA@8`. Для ASCII-строк программы преобразование не нужно.
4. **ReadConsoleA(h, buffer, capacity, &read, 0)** читает строку из консоли.
   В обычном построчном режиме Enter добавляет CR и LF; read включает их.
   Программа проверяет их наличие и исключает из длины числа.
5. **wsprintfA(buffer, format, ...)** форматирует значения в строку, возвращает
   длину без завершающего нуля. Например, формат `%d` задаёт десятичное целое.
   Соглашение CDECL: аргументы убирает вызывающий код. В этой работе не используется.
6. **MOV dst, src** копирует значение; флаги не меняет. Примеры:
   `MOV EAX, x`, `MOV result, EAX`, `MOV EAX, 10`.
   Обычный MOV не копирует напрямую из памяти в память.
7. **PUSH/POP** помещают значение в стек и извлекают его. Для 32-разрядного
   операнда PUSH уменьшает ESP на 4, POP увеличивает на 4. Пример:
   `PUSH EAX`, затем `POP EBX` сохраняет значение EAX в EBX.
8. **PUSHFD/POPFD** сохраняют и восстанавливают EFLAGS; **PUSHAD/POPAD** —
   восемь регистров общего назначения (POPAD пропускает сохранённое значение ESP).
   Для 16-разрядных операндов применяются PUSHF/POPF и PUSHA/POPA.
9. **ADD** складывает два операнда; **ADC** прибавляет также CF;
   **INC** увеличивает на 1, не изменяя CF. Пример: `ADD EAX, 1`.
10. **SUB** вычитает источник; **SBB** вычитает также CF; **DEC** уменьшает
    на 1 без изменения CF; **NEG** меняет знак. Пример: `SUB EAX, '0'`.
11. **DIV** выполняет беззнаковое, **IDIV** — знаковое деление.
    При 32-разрядном делителе делимое — EDX:EAX, частное — EAX, остаток — EDX.
    Для положительного 32-разрядного делимого перед DIV обнуляют EDX;
    перед IDIV применяют CDQ для знакового расширения EAX.
    Для 8 бит: AX / операнд → AL (частное), AH (остаток);
    для 16 бит: DX:AX → AX, DX. Ноль в делителе и слишком большое частное вызывают исключение.
12. **MUL** умножает беззнаковые числа, **IMUL** — знаковые.
    Однооперандная форма для 32 бит умножает EAX на операнд и даёт EDX:EAX;
    для 8 бит AL → AX, для 16 бит AX → DX:AX.
    Двухоперандная `IMUL EAX, x` сохраняет младшие 32 бита в EAX;
    OF/CF показывают, что знаковый результат не помещается. JO проверяет OF.
13. **DB, DW, DD, DQ, DT** выделяют 1, 2, 4, 8, 10 байт соответственно.
    `x DD ?` — неинициализированное двойное слово;
    `buffer DB 64 DUP (?)` — массив из 64 байт.
14. **Регистровая:** `MOV EAX, EBX`. **Непосредственная:** `MOV EAX, 8`.
    **Прямая:** `MOV EAX, x` — чтение по адресу переменной x.
15. **Косвенная регистровая:** `MOV AL, [ESI]`.
    **По базе со смещением:** `MOV EAX, [EBX+4]`.
16. **Прямая с индексированием:** `MOV AL, inputBuffer[EDX]`.
    **По базе с индексом:** `MOV EAX, [EBX+ESI*4+8]`.
    Эффективный адрес = база + индекс × масштаб + смещение; масштаб — 1, 2, 4 или 8.

Аргументы WinAPI в программе передаются через стек справа налево.
Суффикс @20 означает пять 32-разрядных аргументов (20 байт).
Внешние функции могут менять EAX, ECX и EDX, поэтому значения,
которые нужны после вызова, программа сохраняет в памяти.
