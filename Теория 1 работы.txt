SF — Sign Flag произошёл перенос в беззнаковой арифметике Ставится в 1, если результат получился отрицательным

EAX / AX / AH / AL (Accumulator Register — Аккумулятор): Традиционно используется для арифметических операций. Например, результаты умножения и деления процессор по умолчанию сохраняет именно сюда. Также здесь возвращаются результаты работы функций.   
EBX / BX / BH / BL (Base Register — Базовый регистр): Изначально использовался для хранения базового адреса массива или структуры в памяти.
ECX / CX / CH / CL (Counter Register — Счетчик): Процессор аппаратно использует его как счетчик итераций для циклов (команда LOOP автоматически уменьшает ECX на 1) и для строковых операций с префиксами повторения REP.  
EDX / DX / DH / DL (Data Register — Регистр данных): Работает в связке с аккумулятором (EAX) при умножении и делении больших чисел, когда результат не помещается в один регистр (например, при делении двойного слова остаток идет в EDX, а частное — в EAX).   
ESI / SI (Source Index — Индекс источника): Используется для хранения адреса источника данных при копировании строк или блоков памяти (например, для цепочечных команд MOVS и LODS).   EDI / DI (Destination Index — Индекс приемника): Используется для хранения адреса, куда копируются данные в операциях обработки блоков памяти (например, для команд MOVS и STOS).   ESP / SP (Stack Pointer — Указатель стека): Содержит адрес вершины стека (последнего добавленного в стек элемента). Стек растет от старших адресов к младшим, и процессор автоматически сдвигает ESP при командах PUSH и POP.   EBP / BP (Base Pointer — Указатель базы): Используется в качестве точки отсчета для адресации аргументов функции и локальных переменных (так называемый стековый кадр). Процедуры часто копируют в него текущее значение ESP, чтобы не потерять доступ к аргументам при изменении стека.

Директивы — это служебные указания компилятору о том, как собирать программу; в машинный код процессора они не превращаются.
.386 — использовать набор инструкций процессора 80386.
.MODEL — задает модель памяти (например, FLAT) и правила вызова функций (например, STDCALL).  
.DATA — обозначает начало сегмента для хранения данных и переменных.   
.CODE — обозначает начало сегмента с исполняемыми командами.   PROC и ENDP — открывают и закрывают описание процедуры (функции).

PUBLIC — делает локальную процедуру или данные доступными для вызова из других файлов.

Как работает вычитание:
Знаковый бит: Старший (самый левый) бит определяет знак числа: 
0 обозначает положительное число, 
1 — отрицательное.Дополнительный код: 
Формируется путем инверсии всех битов положительного числа и прибавления единицы к результату.
Для оптимизации архитектуры процессор использует один и тот же аппаратный сумматор для разных операций. 
Вычитание (A - B) аппаратно реализуется как сложение (A + дополнительный код B).
В основе дополнительного кода лежит модульная арифметика. Для регистра размером N бит дополнительный код отрицательного числа B математически равен значению $2^N - B$.
При сложении A и дополнительного кода B процессор вычисляет сумму $A + 2^N - B$. 
Слагаемое $2^N$ представляет собой единицу в (N+1)-м бите. 
Поскольку регистр физически вмещает только N бит, этот старший разряд образует бит переноса и автоматически выходит за пределы ячейки памяти. 
Его отбрасывание строго компенсирует преобразование, использованное при создании дополнительного кода, и оставляет в регистре корректный результат вычитания.

Преобразования строк и чисел. Ввод информации с клавиатуры и вывод ее
на экран в консольных приложениях осуществляется только в символьном виде.
При этом каждый символ кодируется одним байтом согласно стандарту
ASCII/ANSI. Таким образом, чтобы ввести число, необходимо сначала ввести
строку, а затем преобразовать ее в двоичное число.
Пример. Формирование числа из строки символов десятичной системы
счисления. Пусть s – исходная строка, ax – результирующее число.
ax = 0;
for (i=0; i<длина_строки(s); i++) ax = ax*10 + s[i] – '0';
Необходимость вычитания из очередного символа строки s[i] символа '0' свя-
зана с тем, что цифры в таблице ASCII имеют коды от 30Н для символа '0' до 39Н
для символа '9'. Таким образом, получаем нужное число путем вычитания из кода
текущего символа кода числа 0.

Стек используется для оперативной работы с переменными и сохранения адреса возврата при вызове процедур и работает по принципу «первым вошел – последним вышел». Адрес вершины стека хранится в регистре ESP.
Extended Stack Pointer
Он хранит адрес вершины стека. В 32-битной программе PUSH обычно кладёт 4 байта и уменьшает ESP на 4. POP забирает 4 байта и увеличивает ESP на 4. В методичке стек описан именно как LIFO, а его вершина хранится в ESP.
Для работы со стеком используются команды PUSH и POP: PUSH источник POP приемник
